# OpenAPI Generator 통합 가이드

우리 프로젝트는 `specs/api/openapi.yaml` 설계도를 **단일 진실 공급원(Single Source of Truth)**으로 삼습니다. 

---

## 1. 기본 원칙
- **직접 수정**: API 구조를 바꾸고 싶다면, 스프레드시트나 다른 도구 대신 `specs/api/openapi.yaml` 파일을 직접 수정합니다. (팀원과의 합의가 선행되어야 합니다!)
- **코드 자동 생성**: 수정된 명세를 바탕으로 각자의 언어에 맞는 코드를 자동으로 생성합니다.

---

## 2. 실행 방법

### 방법 ①: Makefile 사용 (권장)
Docker가 설치되어 있다면 아래 명령어로 즉시 코드를 생성할 수 있습니다.
```bash
make api-gen
```

### 방법 ②: 직접 설치하여 사용
로컬 환경에 직접 도구를 설치하고 싶다면 아래 명령어를 참고하세요.
- **Python**: `pip install openapi-generator-cli`
- **NPM**: `npm install @openapitools/openapi-generator-cli -g`

---

## 3. 추천 제네레이터 목록
어떤 언어를 선택해야 할지 고민되시나요? [추천 제네레이터 상세 가이드](generator_overview.md)에서 본인의 스택에 맞는 이름을 찾아보세요.

---

## 4. 주의사항
1. **명세 우선**: 코드를 먼저 짜지 말고, 명세를 먼저 고쳐주세요.
2. **합의 필수**: 명세 수정은 팀 전체에 영향을 주므로 반드시 소통이 필요합니다.

설계도와 생성 코드를 함께 관리하면 변경 지점을 더 쉽게 추적할 수 있습니다.
